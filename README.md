# CIESTA. website

This repository contains the static site for ciestasolutions.com.

Files added:
- index.html
- assets/css/styles.css
- assets/js/app.js
- CNAME (ciestasolutions.com)
- robots.txt
- sitemap.xml

To publish locally:
1. git clone git@github.com:irpetyos-blip/ciestasolutions-website.git
2. git add . && git commit -m "Initial site"
3. git push origin main

DNS (Cloudflare) — see deployment notes in the repository README.
